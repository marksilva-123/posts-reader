# Posts Reader

Lab Activity 10 scaffold for the Front-End Development 2 posts app. This project is a styled application shell; post data and routes are added in later labs.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Included

- Vite, React, and TypeScript
- Tailwind CSS v4 with the Vite plugin and `@/` source alias
- shadcn/ui `base-luma` theme
- Button, Card, Dropdown Menu, and Skeleton components
- Light, dark, and system theme selection persisted in local storage
